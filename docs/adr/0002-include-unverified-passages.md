# Include minimally labelled unverified passages

Spokes will allow paths whose physical connectivity is known but whose permission for bringing a bicycle is unverified, because these links are central to finding routes that avoid motor traffic. Such sections will be classified as Unverified Passage with minimal visual labelling; only a clear, current passage-level prohibition creates an Explicit Exclusion, and ambiguous or merely bicycle-restrictive data remains eligible for Rider review.
