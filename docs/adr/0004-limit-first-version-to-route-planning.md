# Limit the first version to inspectable route planning and export

Spokes will accept two map-selected endpoints and present only materially distinct Least-Traffic, Recommended, and Faster routes with compact exposure metrics and GPX export. It will not initially provide place search, round trips, live navigation, GPS recording, live closures, weather, satellite imagery, elevation charts, accounts, saved routes, what3words input, via points, segment avoidance, or manual route editing; those capabilities would distract from proving the routing model.
