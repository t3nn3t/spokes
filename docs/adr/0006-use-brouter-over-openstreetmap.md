# Use a customized BRouter profile over OpenStreetMap data

Spokes will self-host BRouter and customize its routing profile rather than build graph search or depend on CycleStreets routing. OpenStreetMap will be the only first-version routable graph; BRouter will produce candidate routes, while Spokes audits their segments to calculate expected motor exposure and Unverified Passage, and any later council rights-of-way data will remain a separate verification overlay.
